## 后续诊断准备

新增Start-AutomaticDiagnosticSession.ps1，可指定配套EXE及GcWorkFloor=0/1；默认0，不启动新实验。它保留自动进程采样，并在后续启动时设置RUST_BACKTRACE=1、每约5秒记录系统提交/上限和可用物理内存。计数读取失败记录unavailable而非0，继续进程采样。

在进程启动后立即保留Handle，并在退出时做有界WaitForExit，用于可靠记录进程退出码。使用独立隐藏PowerShell子进程exit17验证，成功捕获17；脚本语法、实验版ValidateOnly和系统计数查询已验证。尚未用真实崩溃验证新记录链；标准库能否在分配失败时生成完整回溯以实际输出为准。
